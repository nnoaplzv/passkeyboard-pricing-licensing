## 授权条款里，真正决定你花多少钱的四项

商品页上的功能介绍可以先跳过，先找到授权信息那一块，四项必须看清。

| 项目 | 在页面上找什么 | 没看清的后果 |
| --- | --- | --- |
| 授权期限 | 写的是「永久 / 买断」还是「1 年 / 订阅」 | 订阅到期功能就停，续费价还可能变 |

这四项通常写在商品页的「授权详情」里。兑换码到手后，一般要去开发商官网或软件内激活，不是在店铺页面激活，所以买之前先确认自己拿得到激活入口，别等付款了才发现还要注册一堆账号。
